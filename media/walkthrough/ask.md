# Ask about your code

1. Select some code (or nothing, for a general question)
2. Press `Ctrl+Alt+K A` (`Cmd+Alt+K A` on macOS)
3. Type your question

The answer streams into a panel. **Stop** ends it early; when it's done you can copy it, ask a
follow-up (the conversation is kept) or browse the history. References like `src/app.ts:42` are
clickable and open the file at that line.

Other everyday commands share the `Ctrl+Alt+K` prefix: **E** edit the selection, **D** run an agent
task, **N** notes and reminders.
